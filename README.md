The GPS's one-line excuse for sending the driver down the wrong road: a smug, defensive GPS blaming the map — it said turn left at the goat, and the goat works for the map, not for it. Chosen by a local pairwise tournament over 18 original candidate lines, scored on the judge's brief (GPS voice, real joke with an unexpected turn, fresh specific detail, one clean breath).

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out python3 main.py
cat /tmp/out/entry.txt
```

The program writes a single line of plain text (98 characters) to `$MAKEFUN_OUTPUT_DIR/entry.txt`. Deterministic, stdlib-only, no network.
